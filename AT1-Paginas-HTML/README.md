# 📽️ Paginas em HTML 
 
## 🗒️Descrição do Projeto

A Central Dos Jogos é uma plataforma web interativa desenvolvida com foco no universo dos videogames. O site possui uma estrutura multipágina (Home, Xbox, PlayStation, Nintendo e Lançamentos), oferecendo conteúdos direcionados sobre as principais marcas da indústria, análises, novidades do setor e uma seção completa para acompanhar o calendário dos próximos lançamentos.
 
Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End 
Para Web (2026.2)**, "Este website foi desenvolvido com o propósito de demonstrar na prática a estruturação e a navegação entre múltiplas páginas em uma aplicação web.
 
## 🔎 Tecnologias Utilizadas 
* **Linguagem:** HTML5, CSS3
* **Ferramentas:** VSCode 
* **Modelo de IA:** Google Gemini 
 
## 📒Resultados e Aprendizados 
O projeto alcançou resultados sólidos em ambiente de teste, demonstrando 
a eficácia do modelo híbrido. 
* **Estruturação de Conteúdo e Listas:** Formatação de cronogramas e dados sequenciais para apresentar lançamentos e notícias de forma clara ao leitor..  
* **Arquitetura de Informação e Navegação Multipágina:** Organização do código HTML em múltiplas seções interconectadas via marcação semântica (<header>, <nav>, <main>, <article>, <aside> e <footer>).
 
## 🤖 Declaração de Uso Ético da IA 
Este projeto utilizou inteligência artificial (Google Gemini) estritamente como ferramenta de suporte 
tecnológico para [Finalidade, de corrigir o erro de funcionamento do site no https]. Todo o código gerado foi revisado, 
testado e compreendido por mim, garantindo a minha responsabilidade 
integral sobre a autoria final, integridade e funcionamento da 
aplicação.
