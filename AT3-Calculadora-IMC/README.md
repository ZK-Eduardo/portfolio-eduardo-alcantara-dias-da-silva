# 📽️ Paginas em HTML 
 
## 
📝
 Descrição do Projeto 
"Ferramenta interativa focada no cálculo e na classificação do IMC (Índice de Massa Corporal). O sistema categoriza os resultados de forma clara, servindo como base de apoio para análises clínicas e monitoramento de saúde."

Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End 
Para Web (2026.2)**, "Este website foi desenvolvido com o propósito de demonstrar na prática a aplicação, a lógica e o funcionamento do JavaScript em um ambiente web."
 
## 
👨‍💻
 Tecnologias Utilizadas 
* **Linguagem:** HTML5, Javascript
* **Ferramentas:** VSCode
